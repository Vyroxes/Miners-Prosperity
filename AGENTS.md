# Project skills

For Minecraft block/item texture generation, edits or pixel-art variants, read and follow `skills/minecraft-pixel-art/SKILL.md` before starting. This is the authoritative project-local texture skill. Always ask for 16x16, 32x32 or 64x64 if the current task has no explicit resolution. References are in `texture-references/blocks/` and `texture-references/items/`; use existing Miner's Prosperity game textures for its own style.
